# 같이가개

버전: 0.14.1 (공식 사진 바로가기·승인형 갤러리 준비)

소형견부터 대형견까지 반려견과 함께 갈 곳을 찾는 정적 웹 MVP. 하남·남양주·양평의 공개자료 조사 장소부터 시작합니다.

## 실행

Node.js 22 이상, 설치할 의존성 없음.

```sh
npm test
npm run build
npm run check:build
python3 -m http.server 8080 --directory dist
```

`dist/index.html`은 단독 파일로 열어도 작동합니다. 원본 `index.html`은 빌드용 템플릿입니다.

## 현재 상태

- **숙소 사진:** 5곳 공식·공공 사진 페이지 바로가기 제공. 대표 사진·상세 갤러리·비교 썸네일·SEO image는 사용 근거를 기록한 승인 사진만 노출하도록 준비. 현재 재게시 권한이 확인된 사진은 0장이므로 실제 사진 업로드/게시는 미완료입니다. 업체별 원문과 발송하지 않은 사진 제공 요청 초안은 `docs/PHOTO_PERMISSION_REQUESTS.md`에 기록했습니다.

- **숙소 탐색 개선:** 지역 선택 → 간결한 시각 카드 → 최대 3곳 조건 비교 → 상세 핵심 요약 → 출처/문의 흐름. 5곳 모두 상세 페이지를 제공하고 문의 문구·체크리스트는 상세로 이동했습니다. 사진 사용권 확보 전에는 실제 숙소 사진과 구별되는 조건 안내 그래픽만 제공합니다.

- **펜션 확장:** 기존 2곳에 가평 아트·가평 하늘다리·양평 블러썸을 추가해 조사 후보 5곳. 새 3곳은 공식 이용안내의 체중·마릿수·반려견 추가요금·객실/시설 제한과 질문형 답변, 고유 메타데이터·canonical·구조화 데이터를 가진 개별 페이지 제공. 업체 직접 검증/실시간 예약은 미확인, 검색색인 차단 유지.

- **장소 비교:** 검색 카드에서 최대 3곳을 선택해 체중·실내외·요금·운영시간·견종·마릿수·출처 확인일을 비교합니다. 선택은 검색 변경 중 유지되며 새로고침하면 지워집니다. 미확인 값은 그대로 표시하고 현재 입장·영업을 보장하지 않습니다.

- **숙소 문의 준비 체크리스트:** 조사 후보 2곳에 날짜·객실, 반려견 조건, 추가요금, 이용 공간, 환불·공식 예약 채널을 준비하는 체크박스와 기본 초기화 버튼을 추가했습니다. 체크는 방문자가 스스로 문의 내용을 준비하는 기능일 뿐 업체 직접 확인이나 예약 가능 인증이 아니며, 서버·브라우저 저장소에 기록하지 않습니다.

- **숙소 문의 문구 접근성:** 브라우저 클립보드 권한이 거부되거나 자동 복사가 불가능해도 각 숙소 카드의 `복사가 안 될 때 직접 복사하기`를 펼쳐 읽기 전용 문구를 직접 선택·복사할 수 있습니다. 서버 전송·자동 문의·저장 기능은 없고 예약 가능 여부는 미확인입니다.

- **숙소 자료 조사 시작:** 한국관광공사 자료의 댕댕별숲과 숙소 홈페이지의 양평 서종풀 2곳을 펜션 가이드의 **출처 확인된 조사 후보**로 분리했습니다. 실제 등록·운영자 확인·예약 검증 숙소는 여전히 0곳이며, 공식 원문과 업체 확인이 필요한 체중·객실·요금·예약 조건을 구분해 표시합니다. 검색에 펜션을 입력해도 미검증 숙소를 예약 가능한 결과로 제공하지 않습니다.

- **펜션·숙소 확장 준비:** 메인에 `애견동반 펜션·숙소` 진입 카드, `/guides/stays/`에 6가지 숙박 조건 확인 가이드를 추가했습니다. 실제 조사·검증된 숙소는 **0곳**이며 실시간 예약·가격·후기는 제공하지 않습니다. 펜션·반려동물 동반 숙소 검색어는 카페·식당으로 잘못 매칭되지 않습니다. 숙소 검색어 가설은 실제 검색량 미측정 상태로 남깁니다.

- **검색 조건 한눈에 보기:** 실제 결과 목록 위에 검색어·지역·몸무게·방문 조건·저장 필터를 칩으로 표시하고 `조건 전체 초기화`로 한 번에 전체 조사 후보로 돌아올 수 있습니다. 반려견 프로필·저장 장소는 삭제되지 않습니다.
- **배너 공개:** MOULY·아이펫스맘 브랜드 배너는 일반 방문자에게도 표시합니다. 모집형 컨셉만 `?bannerPreview=1&bannerStyle=recruit`에서 시험할 수 있습니다. 외부 쇼핑 링크나 추적은 연결하지 않습니다.

- **개선된 배너 디자인:** MOULY 딥그린·라임과 아이펫스맘 피치·크림 2가지 대비 색상, 자체 SVG 발바닥 일러스트, 후킹 문구, 모바일 반응형 배치를 적용했습니다. 허가받지 않은 상품 사진이나 외부 추적 리소스는 쓰지 않습니다. 배너 자체는 링크 미연결의 디자인 시안입니다.
- **브랜드 안내 공개 모드:** 장소 탐색 결과에서 4개 장소를 본 뒤 MOULY·아이펫스맘 배너를 표시합니다. 일반 방문자에게도 보이며 결과가 1~3개면 목록 끝, 0개면 숨깁니다. 닫을 수 있고 개인정보·클릭 추적이나 외부 구매 링크는 아직 연결하지 않았습니다. 장소 검증·추천 점수와 무관한 광고로 구분합니다.
- 테스트 링크: `https://bins-hub.github.io/gatigagae/?bannerPreview=1`. 모집형 시안은 `?bannerPreview=1&bannerStyle=recruit`에서만 표시합니다. MOULY와 아이펫스맘의 정확한 외부 연결 주소·정식 소재는 아직 미확인입니다.

- **정보 신뢰 상태 공개:** 모든 장소 상세 화면에 외부자료의 유형(상충·경계·영업 확인 필요·공공 관광자료·외부 플랫폼 소개), 확인일, 원문 수, 운영자 직접 확인 여부를 구분해 표시합니다. 검색 결과에도 짧은 경고와 확인일을 보여줍니다. 자료 확인일은 업체 규정 검증일이 아닙니다.
- **정보 정정 메모:** 각 장소의 `정보 오류 메모`에서 오류 유형·변경사항·근거 URL을 작성하여 클립보드에 복사할 수 있습니다. 아직 공개 접수 채널/관리자 인증·DB가 없으므로 **접수·전송·운영자 알림은 하지 않습니다.** 입력 내용은 페이지에만 일시적으로 존재하며 브라우저 저장소나 서버에 보내지 않습니다. 개인정보 입력을 지양합니다.
- 기존 운영자의 오프라인 정정 초안/승인/반려는 별도이며, 메모 복사만으로 업체 정보·`policy`·검색 색인을 변경할 수 없습니다.

- **새 장소 출처 조사:** 양평 하우스베이커리(한국관광공사 소개), 하남 라멘온도 하남미사점·탑탑다이너(제3자 플랫폼이 전하는 매장 공지) 3곳을 추가했습니다. 총 **카페 11곳·식당 2곳**, 업체 직접 입장 규정 검증 **0곳**입니다.
- **검색어 일치 탐색:** 하남 애견동반 식당 검색은 현재 조사된 식당 2곳만 보여주며, `guides/restaurants/`는 자료 출처·이동장·체중·실내 범위 확인 사항을 따로 안내합니다. 카페 후보와 혼동하지 않습니다.
- 신규 3곳 모두 `policy:null`이며 오늘 영업/동반 가능 확정이 아닙니다. 출처가 다른 운영시간/공간·체중 기준은 방문 전 매장에 직접 확인해야 합니다. `noindex,nofollow` 유지.

- **방문 전 체크리스트:** 각 조사 장소 상세 페이지에서 영업·실내 공간·체중/마릿수·필수 용품·요금/주차 5항목을 직접 체크하고 초기화할 수 있습니다. 체크는 해당 화면에만 유지되며 서버나 브라우저 저장소에 남기지 않고, 업체 공식 확인 기록으로 취급하지 않습니다.
- **문의 질문 복사:** 각 장소 상세 화면에서 방문 조건 질문을 클립보드에 복사할 수 있습니다. 업체에 자동으로 발송하지 않습니다. 장소 검색 결과에서 체크리스트로 바로 이동할 수 있습니다.
- **검색 정확성 안내:** `근처`, `오늘`, `실내`, `비 오는 날` 검색 시 검증 좌표·영업 정보·실내 동반 정책이 없는 상황을 검색 결과에 알립니다. 실시간 위치·영업·입장 허용을 추정하지 않습니다.

- **일상 검색어 이해:** `남양주 애견동반 카페`를 지역+업종 조건으로 해석합니다. 현재 자료가 없는 `양평 애견동반 식당`은 카페를 식당처럼 표시하지 않고 자료 부족을 안내합니다. 기존 상호명·주소·몸무게 검색은 유지합니다.
- **실제 검색량 측정 준비:** 네이버·구글 광고 키워드 도구에서 직접 확인한 검색수만 CSV로 검증하여 내부 우선순위에 반영합니다. 검색량은 아직 **미측정 90개**이며, 숫자를 만들어 넣지 않습니다. `reports/search-demand-input-template.csv`는 빈 검색수 양식입니다.
- **검색 색인 준비도:** `reports/search-readiness.json`에 업체 검증·운영 연락처·정보 수정 경로 등 남은 조건을 기록합니다. 자동 색인 허용 기능은 없습니다.

- **검색어와 진입 페이지를 연결:** `남양주 애견동반 카페`와 같은 지역별 페이지에서 정확히 그 지역의 기존 카페 후보·출처·규정 경고를 보여주고, 한 번에 같은 지역으로 필터링된 검색 결과로 이동합니다.
- **첫 방문 몸무게 선택 입력:** 이전의 16kg 기본 적용을 제거했습니다. 반려견 체중을 모르면 전체 후보를 볼 수 있고, 입력한 경우에만 외부자료 체중 제한 후보 필터링을 적용합니다. 저장된 반려견 프로필이 있으면 프로필 값이 반영됩니다.
- 검색 의도 페이지와 지역 페이지는 여전히 외부 공개자료 조사 목록이며 업체 직접 확인 0곳, `noindex` 유지. 유효한 월간 검색수/경쟁도 측정은 하지 않았습니다.

- **검색 의도 기반 탐색:** 첫 화면에서 애견동반 카페 / 강아지랑 갈만한 곳 / 실내 동반 확인으로 바로 이동합니다. 식당 조사 후보 2곳이 생긴 뒤부터 식당 안내 페이지를 제공합니다. 업소 검증은 모두 미완료입니다.
- **새로운 독립 안내 페이지:** `guides/cafes/`, `guides/restaurants/`, `guides/weekend/`, `guides/indoor/`. 모두 기존 조사 후보와 확인 체크리스트에 근거하며 입장을 보증하지 않습니다. 지역 3개·상세 13개 페이지를 제공합니다.
- **키워드 연구 준비:** `keywordResearch.js`에서 예상 검색어 90개를 가설로 생성해 `reports/keyword-hypotheses.csv`에 보관합니다. 검색량·경쟁도는 **측정하지 않았으므로 값이 없습니다.** 실제 데이터 검증 계획은 [검색 의도 계획](docs/SEARCH_INTENT_PLAN.md)을 참고합니다.

- **모바일 UI 개선:** (1) 반려견 몸무게·견종 → (2) 지역·이용 공간 → (3) 조건으로 장소 탐색. 마릿수·요일·장소명 검색은 '더 자세히 찾기'를 펼쳐 설정합니다.
- 검색 결과는 공개자료 체중·실내 조건·업체 검증 여부를 먼저 보여주는 짧은 카드로 바꾸고, 기존 출처·전체 조건은 고유 상세 페이지에서 확인합니다. 기존 문의 문구 복사, 지도 검색, 전화 링크 및 저장하기는 유지합니다.
- 화면 하단 모바일 메뉴: 장소 찾기 / 지역별 / 저장한 곳. 지도 탭은 검증 좌표 확보 전까지 노출하지 않습니다.
- **반려견 프로필은 선택 저장**: 몸무게·견종·마릿수만 `localStorage`에 저장합니다. 저장 버튼을 누르지 않는 한 보관하지 않으며 삭제 버튼을 제공합니다. 서버 동기화·로그인 없음. 저장된 장소는 기존 로컬 즐겨찾기와 독립입니다.

- 업체 정보 정정은 **원본값 확인 → 출처 근거 → 운영자 검토 승인/반려 → 별도 로컬 적용** 절차로 관리합니다. 온라인 관리자 로그인 기능은 아직 없습니다.
- 거리 계산 함수와 확인된 좌표만 받는 준비 코드를 추가했습니다. **현재 근거가 확인된 장소 좌표 0곳**이므로 실제 거리순 검색 UI나 위치 권한 요청은 제공하지 않습니다.
- `reports/geolocation-readiness.json`은 위치 데이터 확보 전 조사 목록으로, 공개 `dist/`에 포함하지 않습니다.

- 장소 ID 기준으로 `places/<id>/` 상세 페이지 10개와 `regions/{hanam,namyangju,yangpyeong}/` 지역별 페이지 3개를 빌드 때 자동 생성합니다. 별도 사이트가 아니고 기존 같이가개 GitHub Pages의 하위 주소입니다.
- 모든 상세/지역 페이지는 외부 공개자료의 출처·주의 문구를 표시하며 검증 전 `noindex,nofollow`입니다. 지도는 네이버 지도 **검색 링크**이지 검증 좌표가 아닙니다.
- `reports/review-queue.csv`는 빌드에서 자동 생성하는 **비공개 개발용 조사 목록**입니다. `dist`에 넣지 않으며 `.gitignore`로 원본 저장소 제출도 제외합니다.
- `docs/DEVELOPMENT_ROADMAP.md`를 진행 상태의 유일한 기준 문서로 관리합니다.
- `reviewAudit.js`: 운영불명·주소 충돌·90일 경과 우선순위 보고서 `reports/verification-priority.csv`를 생성합니다. `correctionDraft.js`와 `tools/propose-correction.mjs`는 출처 포함 **승인 대기 초안만** 작성하며 실제 공개 규정에 자동 반영하지 않습니다.
- `.github/workflows/deploy-pages.yml`: 운영자가 Pages 설정을 GitHub Actions로 전환하면 자동 발행할 수 있도록 **비활성 상태로 준비**되어 있습니다. 기존 Pages는 수동 `gh-pages` 게시를 유지합니다.

- 체중·지역·실내외·장소명/주소 검색에 **견종·동반 마릿수·방문 요일** 입력을 추가했습니다. 체중 제한 후보 제외(해제 가능), 자료 충돌 경고, 상담 문구 복사, 즐겨찾기, 상세 팝업, 외부 지도 검색도 유지됩니다.
- 정확한 입장 판정은 **업체 직접 검증 정책**이 있는 경우에만 가능합니다. 확인되지 않은 견종·다견·요일 조건은 미확인으로 표시됩니다.
- 장소마다 `research.additionalConditions`를 두어 견종·마릿수·요일별 공개자료를 관리합니다. 이는 실시간 운영 규정이 아닙니다.
- `validation.js`가 중복 장소, 출처, 정책 값 오류를 검사하고 `tools/check-build.mjs`가 빌드 결과를 점검합니다.
- 공개자료에서 체중 초과가 명시된 장소만 기본 후보에서 제외합니다. 출처끼리 충돌하거나 규정이 미확인인 장소는 임의로 제외하거나 입장 가능하다고 확정하지 않습니다. **전화는 사용자가 직접 걸어야 하며, 문의 복사는 실제 발송이 아닙니다.**
- 실제 장소 조사 후보 10곳을 공개자료·매장 소개·지자체 관광 정보로 보강했습니다. **업체 최신 정책 직접 검증 완료 0곳**. 후보의 존재/영업/입장 조건을 보증하지 않습니다.
- 각 장소에 `research` 객체(자료 조사일, 주소, 전화, 요금, 체중·실내외 조건, 충돌 경고, 원문 링크)를 기입했습니다. `research.reviewedOn`은 사이트 담당자가 외부 공개자료를 확인한 날짜이며 업체 확인일이 아닙니다. `policy`는 여전히 `null`입니다.
- 정책 미확인/충돌/90일 초과/미래 날짜는 확인 필요. 체중 상한의 미만/이하 구분.
- 외부 지도는 검색 링크이며 개별 매장의 정확한 위치/길찾기 확정 링크가 아닙니다.
- 제보 접수·전화 발신·예약·광고·MOULY 상품 연결·통계는 미연결. 전화 링크는 휴대전화의 전화 앱만 열고, 문의 문구는 직접 복사·전송합니다.
- noindex 및 robots 차단: 공식 검증과 운영 안내를 갖춘 뒤 공개 검색 허용 여부를 결정합니다.

## 정책 데이터

`data/places.json`의 `policy`를 공식 자료 확인 후 아래 형태로 입력합니다. 예시 URL은 테스트 전용이며 실제 데이터에 넣지 마세요.

```json
{"verifiedOn":"실제 확인한 YYYY-MM-DD","sourceUrl":"https://업체-공식-안내","maxKg":20,"inclusive":true,"unlimited":false,"zones":{"indoor":true,"outdoor":null},"conflict":false}
```

무게 미수집은 `maxKg:null, unlimited:false`입니다. 무제한을 명시한 자료가 있을 때만 `unlimited:true`를 사용합니다. `zones`의 `null`은 미확인입니다. 정책 원문과 구역·견종·필수 용품·요금 조건을 추가 기록한 후 공개 데이터로 승격하세요. 체중 조건 일치는 입장 확약이 아닙니다.

후보 발견 출처는 각 레코드에 있습니다. 제3자 소개는 정책 확정 근거로 사용하지 않았습니다. 사진·리뷰·소개문을 복제하지 않았습니다. 일러스트는 프로젝트 내 SVG입니다.
