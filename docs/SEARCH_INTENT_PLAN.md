# 같이가개 검색어·검색 의도 개발 계획

마지막 확인: 2026-10-27. **본 문서와 CSV의 키워드는 검색량을 측정한 결과가 아니라 사용자 의도를 바탕으로 만든 조사 후보**입니다. 현재 실제 월 검색량·키워드 경쟁도·CTR 수치를 확보하지 않았습니다.

## 개발한 정보 구조

- 사용자 첫 방문: **방문 목적 선택 → 지역별 안내 → 실제 조사 장소 → 입장 규정·출처 확인**
- 자세한 검색을 원하는 보호자: 기존 체중·견종·지역·실내외·마릿수·요일 필터 유지
- 업체 정보가 없는 주제는 링크 없는 **자료 조사 중**으로 표시하고 빈 가짜 목록을 만들지 않음
- 모든 랜딩 페이지에는 고유한 질문, 실사용 확인 절차, 다른 페이지와 연결하는 탐색 경로, 업체 직접 검증 전 안내 포함
- 실제 산책로·식당·숙소, 실내 이용 가능 확정 장소를 만들어내지 않음

## 검색 수요 검증 작업 (아직 미완료)

1. 네이버 검색광고 키워드 도구에서 검색어별 월간 검색량·기기별 검색수·경쟁 지표를 수집하고 **조회일·기준·출처**를 따로 기록합니다. 사용할 수 없는 지표는 빈칸으로 둡니다.
2. 네이버 데이터랩에서 묶음 주제의 **상대 검색 관심도**를 비교합니다. 그래프 지수를 월간 절대 검색수처럼 변환하지 않습니다.
3. 네이버·구글에 실제 검색어를 입력해 검색 의도를 육안 분류합니다. 블로그·지도·광고가 중심인지 확인하되 경쟁도를 검색 결과 개수만으로 단정하지 않습니다.
4. 사용자에게 제공할 고유 가치가 있는 페이지에 한해 실제 업체 규정 검증 자료를 축적하고 공개 여부를 결정합니다.
5. Search Console / 서치어드바이저에 공개된 뒤에야 실제 노출 검색어·클릭·CTR을 측정해 우선순위를 재설정합니다.

## 색인 차단 유지

2026-10-27 기준 업체 현재 입장 규정 직접 검증은 **0곳**입니다. \`robots.txt\`의 전체 차단, 각 HTML의 \`noindex,nofollow\`를 유지합니다. 따라서 **지금 페이지가 생겼다고 검색엔진 유입이 즉시 발생하는 것은 아닙니다.** 사이트 품질·운영/정정 정보 확보 후 검색 공개를 별도로 검토합니다.

## 페이지 확장 기준

- 실측 검색량이 높아도 해당 의도에 맞는 검증 정보가 없는 경우 페이지 발행 보류
- 지역명·동의어만 바꿔 유사한 목록을 수십·수백 개 생성하지 않음
- 정규 제목, 한 페이지의 고유 주제, 실제 원문 출처, 오래된 정보의 최신성 경고
- 정합성 검증과 내부 링크 검사 통과 후 공개
