# 숙소 사진 적용 현황·제공 요청 초안

2026-10-29 갱신: 댕댕별숲의 TourAPI 개방사진 5장을 공공데이터포털 이용 안내에 근거해 적용. 업체 개별 요청 발송 0건. 나머지 4곳은 사용 근거 미확보.

공개 이용 근거: https://www.data.go.kr/data/15101578/openapi.do — 한국관광공사 국문 관광정보 서비스는 사진을 포함한 선별 개방 자료를 웹 등에서 활용하도록 제공하며 사진은 공공누리 1·3유형이라고 안내한다. 개별 사진을 특정 유형으로 단정하지 않고, 원본 CDN 사진의 전체 비율을 유지하고 편집하지 않으며 출처를 표시한다.

공식 사진이 존재하는 것과 같이가개에 재게시할 수 있는 것은 구분한다. 현재 공식·공공 원문 사진 바로가기는 5곳 모두 제공한다. 승인된 사진만 카드·상세 갤러리·비교표 및 SEO image에 노출하도록 `stayPhotos.js`에서 제어한다.

## 업체별로 이름을 넣어 보낼 수 있는 요청 초안

안녕하세요. 반려견 동반 장소 안내 사이트 ‘같이가개’를 준비하고 있습니다.

[숙소명]을 소개하는 페이지의 대표 사진 1장과 상세 사진 3장(객실·마당·외관)을 제공받고 싶습니다. 사진의 객실명/구역과 촬영 시점, 반려견 이용 가능 구역도 함께 알려주시면 정확하게 표시하겠습니다.

같이가개 웹사이트의 목록·상세·비교 화면에 출처를 표시하여 게시해도 되는지, 광고가 있는 페이지에서도 이용 가능한지 확인 부탁드립니다. 사진 위에는 글자를 넣지 않으며, 크기 조정·압축·자르기 허용 범위와 표기할 출처명, 수정·삭제 요청 방법도 알려주세요. 제공하시는 분께서 사진의 재사용을 허락할 권한이 있는지도 확인 부탁드립니다.

함께 확인할 내용: 객실별 반려견 체중·견종·마릿수, 반려견 추가요금, 마당 울타리와 수영장 이용 조건.

## 수신 후 적용

1. 제공자·사진 사용 범위·증빙 위치·출처명을 기록한다. 연락처 등 개인정보는 공개 Git에 넣지 않는다.
2. 대표 사진과 공간별 사진의 숙소 동일성·실제 구역을 확인하고 alt/캡션/가로세로 크기를 기록한다.
3. 권리 근거를 확인한 뒤에만 해당 레코드를 approved로 바꾼다. 빈 근거나 주관적인 ‘홍보용 추정’으로 승격하지 않는다.
4. 원본 변경 금지 조건이면 자르기·색보정·문구 삽입 없이 비율을 유지한다.
5. 이미지가 실제로 로드되는지 PC/모바일에서 검사하고 배포한다. 사진 확보가 업체 운영 규정·예약 검증을 뜻하지는 않는다.
